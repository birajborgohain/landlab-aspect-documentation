Error-1: Python Callback API Mismatch: ``update_until()`` Missing Required Argument
===================================================================================

Description
-----------

The simulation starts successfully and initializes ASPECT, MPI, and the
Landlab components. However, execution fails at the first timestep because
the Python callback ``update_until()`` is called with an incorrect number of
arguments.

Command
-------

.. code-block:: bash

   /opt/homebrew/bin/mpirun -np 23 \
     /Users/biraj/software/landlab_aspect/aspect/build/aspect-release \
     original_ll.prm

-------------------

A geometry warning is printed before the simulation begins.

.. code-block:: text

   Point 0:   -500    100000
   Point 1:   -250    100000

Failure
-------

The simulation reaches the first timestep and then terminates.

.. code-block:: text

   Solving mesh displacement system... 0 iterations.

   *** Timestep 0:  t=0 years, dt=0 years

   TypeError:
   update_until() missing 1 required positional argument:
   'dict_variable_name_to_value_in_nodes'

ASPECT subsequently reports

.. code-block:: text

   update_until returned NULL

before throwing a C++ exception.

Exception
---------

The exception originates from

.. code-block:: text

   source/mesh_deformation/landlab.cc

specifically from the helper function

.. code-block:: cpp

   call_python_function(...)

which attempts to execute the Python callback

.. code-block:: python

   update_until(...)

Since the Python interpreter raises a ``TypeError``, the function returns
``NULL`` to C++, producing the following exception:

.. code-block:: text

   Exception:
   call_python_function(...)
   update_until returned NULL

Finally, ASPECT aborts the simulation with

.. code-block:: text

   MPI_ABORT

Root Cause
----------

The Python function expects an additional required argument that is not
supplied by ASPECT.

Python interface:

.. code-block:: python

   update_until(
       end_time,
       dt,
       uplift,
       dict_variable_name_to_value_in_nodes
   )

Current ASPECT call:

.. code-block:: python

   update_until(
       end_time,
       dt,
       uplift
   )

Because the required argument
``dict_variable_name_to_value_in_nodes`` is omitted, Python raises

.. code-block:: text

   TypeError:
   update_until() missing 1 required positional argument:
   'dict_variable_name_to_value_in_nodes'

This indicates an API mismatch between the Python implementation and the
C++ interface in ``source/mesh_deformation/landlab.cc``.

Execution Flow
--------------

The sequence of events is

.. code-block:: text

   ASPECT
      │
      ├── calls Python callback
      │
      ├── Python raises TypeError
      │
      ├── PyObject_CallObject() returns NULL
      │
      ├── call_python_function() throws an exception
      │
      ├── ASPECT aborts on rank 0
      │
      └── MPI_ABORT terminates all MPI processes

Thus, MPI is **not** the source of the failure; it only propagates the
fatal exception generated by the Python callback.

Resolution
----------

The Python and C++ interfaces must use the same function signature.

Possible solutions include:

1. Modify the Python implementation to accept the older interface.

2. Modify ``source/mesh_deformation/landlab.cc`` so that it passes
   ``dict_variable_name_to_value_in_nodes`` when invoking
   ``update_until()``.

3. Maintain backward compatibility by providing a default argument:

.. code-block:: python

   def update_until(
           end_time,
           dt,
           uplift,
           dict_variable_name_to_value_in_nodes=None):
       ...
